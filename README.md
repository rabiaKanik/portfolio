# Rabia Kanık — Portfolio

Personal portfolio built with React, TypeScript, Vite and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build into /dist
```

## Edit content

All text, links and lists live in `src/data.ts`. Search for `TODO` to find the placeholders
(email, LinkedIn, GitHub, graduation year). Put your CV in `public/cv.pdf`.

## Deploy (Vercel)

1. Push this folder to a new GitHub repository.
2. Go to vercel.com → Add New Project → import the repo.
3. Vercel detects Vite automatically → Deploy.
